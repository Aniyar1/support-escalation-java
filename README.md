# SupportFlow — эскалация обращений

Небольшое настольное приложение на Java Swing демонстрирует паттерн **Chain of Responsibility**. При запуске открывается отдельное окно: можно добавлять обращения, просматривать очередь и видеть, как запрос проходит по уровням поддержки.

## Интерфейс

- **«+ Новое обращение»** — введите тему и описание, выберите серьёзность.
- **«Загрузить примеры»** — добавьте четыре демонстрационных обращения.
- **«Очистить»** — очистите журнал эскалации.
- Таблица показывает ID, тему, серьёзность и уровень, на который назначено обращение.

Правила маршрутизации: низкая серьёзность обрабатывается на L1, средняя — на L2 после передачи с L1, высокая и критическая — на L3 после эскалации через L1 и L2.

## Структура паттерна

- `SupportHandler` — абстрактный обработчик и ссылка на следующий уровень.
- `Tier1Handler`, `Tier2Handler`, `Tier3Handler` — конкретные обработчики уровней.
- `SupportTicket` — обращение с уровнем серьёзности.
- `Main` — Swing-интерфейс, формирование цепочки и передача обращений.
